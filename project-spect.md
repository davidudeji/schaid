Project Specification: Complete School ERP Core System1. Module 1: The Core Administration PillarThis module handles high-level infrastructure, logistics, and institutional configuration.

👥 User Management & Role-Based Access Control (RBAC)System Mechanism: A secure multi-tenant routing wrapper checks user identity tokens on every page load.Role Definitions:Admins: Full read/write/delete privileges across all platform datasets.Lecturers: Access to class registers, grading matrix interfaces, and personal HR dashboards.Students: Access to individual custom timetables, grade views, and payment gateways.Parents: Read-only view of linked student profiles, grades, attendance logs, and open bills.Class Reps: Standard student access elevated with secondary permissions to share/broadcast active attendance QR codes.

📝 Admission & Onboarding PortalApplication Pipeline: Digital forms allowing prospective candidates to submit bios, course selections, and identity details.Document Verification Hub: Admin dashboard to view uploaded files (PDF/JPEG transcripts, IDs) with one-click "Approve" or "Reject with Comment" flags.Digital Registration: Automated issuance of unique matriculation/student identification numbers upon final admin sign-off.

💼 Human Resources & PayrollStaff Tracking: Centrally logged staff profile records tracking contract types, active courses, and department alignments.Payroll Engine: Automated calculation dashboards tracking base monthly salaries, performance bonuses, tax deductions, and net disbursements.Leave Workflow: Digital submission pipeline for staff leave requests with automated notification emails forwarded to department heads.

📦 Inventory & Asset ManagementResource Registries: Searchable inventory tables tracking physical school property, lab kits, and tech equipment.Library Logs: Check-out/check-in digital logbook monitoring book allocations, borrow durations, and automated overdue book alerts.Classroom Allocation Map: Structural matrix showing active bookings of physical rooms to avoid double-booking lecture halls.2. Module 2: The Academic & Classroom PillarThis module tracks actual educational delivery, teaching schedules, and student performance metrics.

📚 Course & Curriculum ManagementAcademic Framework: Structures departments, degree pathways, course definitions, credit weight allocations, and prerequisites.Syllabus Repository: Centralized material storage allowing lecturers to upload reading lists, goals, and weekly schedules accessible to registered students.

🗓️ Timetable & Scheduling EngineMaster Schedule Generator: Interactive calendar backend mapping out classes, upcoming exams, and designated venues.Conflict Prevention: Pre-flight client validation logic that blocks admins or students from scheduling two entities into the same room or timeframe simultaneously.

⏱️ Attendance Management (Dynamic QR Loop)QR Generation: Lecturers instantly generate a unique, time-blocked QR code right from their dashboard at the start of a lecture.Delegated Sharing: Enables lecturers or admins to push the QR live onto a projector screen, or route it directly to the designated Class Rep's device for localized scanning.Verification Check: Students use their mobile portal to scan the active graphic, instantly executing an optimistic UI update on the lecturer's attendance roster view.

📊 Examination & GradebooksGrading Matrix: High-density spreadsheet UI for continuous assessment scores (CAs), quizzes, and final exam inputs.GPA Automation Engine: Background logic calculates Grade Point Averages (GPA) and Cumulative GPAs (CGPA) automatically, instantly outputting clean printable report cards.3. Module 3: The Financial PillarThis module operates as the financial ledger, automated billing, and secure payment processing core.

🧾 Fee CollectionAutomated Invoicing: System fires off bulk itemized invoices at the start of each semester for tuition, lab use, and housing.Debtor Ledger: Admin dashboard displaying real-time tracking of paid balances, outstanding debts, and upcoming payment plan timelines.

💳 Online Payment GatewaysIntegration Framework: Secure connection hooks linking the application directly to prominent processing endpoints like Stripe, Flutterwave, or PayPal.Receipt Automation: Generates instant digital ledger entries and emails a downloadable PDF invoice copy to the user upon transaction verification.

📉 Expense TrackingPayout Outlets: Financial panels allowing accountants to log campus operational expenses, vendor bills, and utility payments.Health Reporting: Live balance charts contrasting seasonal fee collections against operational expenses to map monthly net margins.4. Module 4: The Communication & Portal PillarThis module keeps all stakeholders synced with unified, secure views of relevant data.

🖥️ Dedicated PortalsStudent Workspace: Unified landing page containing current semester timetables, assignment tasks, pending balances, and term grade cards.Parent Overview: Read-only portal mapping linked child attendance tracks, performance highlights, and direct fee clearance links.

📢 Mass NotificationsDispatch System: Admin panel capable of firing targeted broadcast messages over SMS, Email, or internal System Push alerts.Categorization: Tags warnings based on priority (e.g., Urgent: Campus closure alerts, Standard: Term calendar updates, Individual: Fee payment warnings).5. Technical Implementation Details for AI GenerationTarget Architectural GoalsFrontend State Speed: Utilize TanStack Query for lightning-fast caching of massive administration datasets (User grids, Grade tables).UI Predictability: Generate components utilizing Tailwind CSS classes combined with Shadcn UI primitives to keep code formatting clean and highly consistent for AI-driven modifications.Data Layout Schema: Instruct the AI assistant to structure core components using independent TypeScript interfaces for strong data validation rules.
